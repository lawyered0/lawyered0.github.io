Current beta scope

Verified on macOS with Python 3.12. Claude uses Desktop Code Local; Codex uses project-local skills and a local project.

A delegated Gmail self-test covered a complete body, resumable DOCX review, and repeat deduplication. Ordinary-host Gmail and live IMAP/REST remain experimental and unverified. Windows, Linux, cloud hosts, live OCR, and other runtime versions remain unverified or excluded.

Use with professional judgment.

LawyeredOS is software, not legal advice. Verify facts, law, deadlines, calculations, document changes, and final work before relying, sending, signing, filing, or serving. Local files are not the same as offline processing: selected content may be sent to Anthropic or OpenAI under your account, settings, and terms.
