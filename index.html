Setup

Open. Ask. Review.

Download and extract the ZIP. Open its folder in the Claude desktop app’s Code tab and choose Local. Then paste:

Set up LawyeredOS for me. Follow the setup instructions in this folder, ask me what you need, and check with me before changing existing files.

Claude shows the complete setup plan before writing and asks you to connect Gmail, skip it safely, or choose the experimental read-only route. It never silently disables email or enables automatic sending. Start with a new empty workspace and fictional data.

No terminal required

The normal path is prompt-first in Desktop Code Local. A terminal fallback and complete install, update, rollback, dependency, and troubleshooting instructions are included in the download.

Current beta scope

Verified on macOS with Claude Desktop Code in a Local session and Python 3.12.

Windows and other operating systems are not supported. Claude Gmail is user-connected and locally unverifiable; the local Gmail adapter, Calendar, OCR, and the complete multi-lens review remain experimental or optional.

Use with professional judgment.

LawyeredOS is software, not legal advice. Verify facts, law, deadlines, calculations, document changes, and final work before relying, sending, signing, filing, or serving. Local files are not the same as offline processing: selected content may be sent to Anthropic under your Claude account, settings, and terms.
